Frequently Asked Questions

Do I need a Usenet provider account?
Yes. EasyNZB is a Usenet (NNTP) download client — it doesn't provide access to Usenet itself. You'll need an account with your own Usenet provider, which gives you a server hostname, port, and login credentials to enter into EasyNZB.
How do I add a Usenet server?
Open Preferences and add a server with its host, port, SSL setting, and your username/password. Use "Test Connection" to confirm it works before saving. You can add more than one server and set a priority — lower-priority servers are tried first, with higher-priority ones used as fallback (e.g. a backup provider).
How do I start a download?
Drag and drop an .nzb file onto the EasyNZB window, or use the "Add NZB…" button to pick one from a file picker. EasyNZB queues it and begins downloading from your configured server(s).
What do "Verify & repair with par2" and "Extract archives automatically" do?
These optional Preferences toggles use the command-line tools par2 and unar to repair incomplete downloads and unpack archives automatically once a download finishes. They aren't bundled with EasyNZB — install them first with brew install par2 unar in Terminal.
Where are my downloads saved?
Wherever you set as the destination folder in Preferences > Downloads. Click "Choose…" to pick a different folder at any time.
Can I limit download speed or the number of simultaneous downloads?
Yes — in Preferences > Throughput, use the Max Speed slider (or leave it at 0 for unlimited) and the "Simultaneous downloads" stepper to control how many jobs run at once.
Can I pause downloads temporarily?
Yes — the global "Pause For…" control lets you pause all downloads for a preset duration, from 15 minutes up to 4 hours, which is handy around bandwidth caps or scheduled maintenance windows.
Why does EasyNZB ask for permission to access a folder?
EasyNZB runs inside Apple's App Sandbox, so it can only write to a folder you've explicitly granted it access to. Once you choose a destination folder, EasyNZB remembers it (via a security-scoped bookmark) so you won't be asked again for that same location.
Does EasyNZB send any of my data anywhere?
No. EasyNZB has no account, no server of its own, and makes no network requests other than the connections to the Usenet server(s) you configure. Your server credentials stay in the macOS Keychain. See our Privacy Policy for full details.
The app isn't working as expected — what should I do?
Try closing and reopening the app first, and double-check your server settings with "Test Connection" in Preferences. If the issue persists, email us at tucmetcalf@gmail.com with a description of the problem and we'll look into it right away.
